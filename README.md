## 🏝️ 本版本亮點（3F 造島自然微縮世界）

本版本為 3F 造島深度施工版：
1. **真實自然高低差地形**：南竿、北竿、東引、莒光真實山海斷崖與梯田。
2. **動態波浪海面與巡弋客輪**：正弦動態浪花起伏，穿梭於島嶼間的「臺馬之星」與「南北之星」客輪。
3. **閩東特色建築**：芹壁花崗岩人字砌與丁字砌石屋、鮮明朱紅起翹馬鞍形封火山牆、壓瓦石防颱工藝。
4. **4～6層連棟公寓示範群**：外掛透明景觀電梯、屋頂綠能防水隔熱綠膜與管線整理。
5. **莒光銀髮安心樂活圈**：門前無障礙緩坡道、紅色防滑扶手、高齡弱勢加碼 30 萬。
6. **40 組情境即時試算器**：內建三取小核心檢核機制，支援 40 組情境快速載入代入試算。
7. **50 題官方 QA 手冊**：支援全文關鍵字即時模糊檢索與手風琴摺疊。
8. **32 家耐震初評機構名錄**：卡片化排版，手機點擊電話號碼立即撥號。
9. **獨立檔案資料庫**：Word 申辦表格、PDF 宣傳手冊、JSON 數據庫單獨存放，隨時下載。
